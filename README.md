# Кейс-задача № 2 — интерактивный счётчик

Приложение на HTML, CSS и ванильном JavaScript для учебной практики.

## Как запустить

Откройте файл `index.html` двойным щелчком в любом современном браузере. Установка дополнительных программ не нужна. Интернет не требуется.

## Возможности

- Кнопки «+» и «−» изменяют значение на единицу.
- Положительное число отображается на жёлтом фоне, отрицательное — на зелёном, ноль — на красном.
- Диапазон ограничен значениями от −10 до 10; на границах соответствующая кнопка блокируется.
- При достижении границы выводится сообщение «Вы достигли экстремального значения».
- Центрирование элементов, градиентный фон страницы и кнопок, радиус кнопок 5 px.

## Файлы

- `index.html` — разметка.
- `style.css` — оформление.
- `script.js` — логика счётчика.

## Ручная проверка

1. После запуска отображается 0 на красном фоне.
2. Нажмите «+»: отображается 1 на жёлтом фоне.
3. Нажмите «−» дважды: отображается −1 на зелёном фоне.
4. Дойдите до +10: кнопка «+» блокируется, появляется сообщение.
5. Уменьшите до −10: кнопка «−» блокируется, появляется сообщение.
6. При уходе с границы сообщение исчезает, кнопка вновь становится активной.
